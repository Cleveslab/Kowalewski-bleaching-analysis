# Kowalewski-bleaching-analysis
## Description
This repository contains R code used to generate all figures and their underlying data from Kowalewski et al. 2026 (link-to-be-updated)

## Folder and file descriptions
- **Kowalewski-bleaching-analysis.Rproj** - The R Project file that manages the environment and working directory to perform analyses and generate figures.
- **Kowalewski_bleaching.rmd** - The R Markdown file that contains all code used to perform analyses and generate figures.
- **Kowalewski_bleaching.pdf** - The knit output from running the entirety of the R Markdown file. Opening this will show you all of the code and the figures generated by each piece of code.
- **Kowalewski_bleaching.md** - The raw knit output from running the entirety of the R Markdown file.
- **README.md** - README document that you are reading right now.
- **renv.lock** - captures the exact state of the R project and its dependencies.
- **renv** - Contents of the R environment (packages and their versions) used to run these analyses.
- **/Data/** - Contains all data files used to perform all analyses and generate plots.
- **/Figures/** - Contains all figures generated by R Markdown file.

## Requirements for running the "Data_analyses.rmd" code
- R 4.5.3
- Bioconductor 3.18

## Setup
1. Install R 4.5.3 from https://cran.r-project.org
2. Open "Kowalewski-bleaching-analysis.Rproj" in R and run:
   install.packages("renv")
   renv::restore()
3. Open and knit the rmd file.

## To see summary of analysis
Please open "Kowalewski_bleaching.md" on Github to see output from rmd file.
